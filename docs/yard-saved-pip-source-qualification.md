The normal Yard entrypoints remain byte-identical to live `9b6b96b4`. Worker,
reconciliation and admission flags are source-owned and default off. The new

## Qualified boundary

One canonical prop, one active Pip, one bowl and a source-selected stay below
60 minutes. The deterministic full visitor/activity pool is unchanged; unsupported
results are never rerolled. An unresolved intent survives process loss. Preparation
runs in the sealed worker after the winning player commit; notification re-enters
the real lock and checks the fresh account version, exact key, state and stock.
Admission validates a prospective Yard snapshot before assigning its one serving,
one use, petbook, visit and event receipt together. Replay reconstructs the sealed
source plan before active presentation or exact departure reward. Food expiry is
processed without consuming another serving; target reservation ends at 84%.

## Remaining integration gates

Normal simulator/action/snapshot wiring, full 45–110-minute event ordering,
multiple props/visitors, post-release layout edits, interrupted player commands,
and the ordinary app renderer are not qualified here. The isolated projection
is mutable:false. The actual game must reconcile an overdue expiry or departure
before presenting current authoritative state; read/project fail pending when
those effects are due. This source checkpoint alone authorizes no runtime
activation, image publication or deployment.
