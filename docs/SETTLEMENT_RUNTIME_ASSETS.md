# Settlement Runtime Assets

This is the current source of truth for Settlement runtime assets. The old
`README_ASSETS_V2.md` and `assets-manifest-v2.json` described a PNG checklist
package and are intentionally removed.

## Runtime Contract

- Runtime assets live under `public/games/settlement/`.
- The shipped runtime format is WebP only. PNG and JPG files must not be added
  to this folder.
- The playable map is one cohesive opaque region asset:
  `map-region-settlement-playable.webp` at 4096x2304. It contains terrain,
  rivers, waterfalls, cliffs, bridges, roads, central plaza, and empty building
  pads as one plane. Runtime no longer composes a separate forest background,
  ground island, or staged road overlays.
- Top-level WebP assets are preprocessed offline to remove the same
  magenta/green chroma-key pixels that the old client-side canvas path removed.
  The opaque natural-color region asset is exempt from chroma-key leak failure
  because its foliage and river colors are real art, not transparent matte
  residue.
- Trimmed Pixi object textures live under
  `public/games/settlement/processed/*.trim.webp`.
- `processed/processed-manifest.json` is generated by the asset script and
  records the current processed texture set.
- Settlement runtime code must load WebP assets directly. It must not use
  `getImageData`, `toDataURL`, `willReadFrequently`, or client-side canvas
  chroma-key/trim work.

## Commands

Regenerate and audit the runtime asset contract:

```bash
pnpm run settlement:assets:process
```

Prepare the current mockup-aligned playable region from the checked-in source
image:

```bash
pnpm run settlement:region:prepare
```

Audit without rewriting assets:

```bash
pnpm run settlement:assets:audit
```

The audit must report:

```json
{
  "nonWebpRuntimeFiles": [],
  "missingProcessed": [],
  "topLevelFailures": [],
  "processedFailures": []
}
```

## Implementation Notes

- `src/games/settlement/assetRegistry.js` owns asset URL helpers, including
  `trimmedAsset()`.
- `src/games/settlement/SettlementGame.jsx` owns the Pixi preload lists and
  should load the region as the base world layer, then request trimmed textures
  only for buildings, props, selection rings, and similar object layers.
- `assets-source/imagegen/settlement/map/` keeps the selected source PNG, final
  prompt, and manifest for the playable region. The generated source is copied
  into the repo before `settlement:region:prepare` writes the WebP runtime file.
- `scripts/settlement-assets.mjs` is the only supported way to regenerate the
  preprocessed runtime textures.
