## Public seam and coordinate contract

`sampleMikaLocomotion(route, calibration, timeSeconds)` returns one navigation-owned world root, 22 root-relative absolute armature bone matrices, phase, four world-space contacts, and reach diagnostics. Row-major 4x4 matrices use source axes +X forward, +Y lateral, +Z up, and source units. World bone pose is `translation(root.position) * rotationZ(root.heading) * boneMatrices[name]`. Apply this root exactly once. The matrices are not glTF node-local transforms; the eventual renderer must derive each bone local from its parent and perform one source-axis conversion. Do not run baked root tracks alongside this pose.

`{kind:'accepted-p2-reference', mirror:false|true}` is a deterministic regression route. `createMikaLocomotionRoute(rootAt, calibration, options)` prepares a bounded fixed-route table from a source-root function with continuously unwrapped heading and adequate history/lookahead. It copies sampled positions/headings and retains no caller callback or data. Position and phase interpolate linearly; heading uses cubic Hermite with fixed central-difference derivatives. Root travel is currently restricted to the source cruising speed 0.74 units/s; arbitrary speed and stop/start are explicitly refused pending their own scheduler qualification. Both sampled and interpolated yaw rates must stay within the original peak, allowing 0.000001 rad/s numerical reconstruction tolerance. Unreachable poses throw and cannot be consumed as valid output.

Cadence uses the source's explicit measured peak yaw rate, 1.0334182967717993 rad/s, rather than a new route's global maximum. Straight routes therefore have a finite 0.92 s period. Parameters for paws, support load, body transfer, swing arc/pitch and curvature response are unchanged.

## Verification

Run `node --test tests/*.test.mjs` from this directory with Node 24. No installation. The native test uses the included exact Three186 vendor modules (MIT license retained) and unchanged source GLBs. The locomotion-only test has no dependencies.

Prepared routes own a deep-frozen calibration snapshot. Each sample must supply an identical serialized calibration; changed parameters reject before pose output. The caller's root callback is used only during preparation and discarded.

`createMikaNativePoseDriver(THREE, gltf, calibration)` owns one outer navigation Group and applies root-relative transforms as native parent-local bones. The baked AnimationMixer is never started. No custom coat shader, material or geometry changes. All 25 evaluated skins reproduce the baked original/mirror at source witness times: 764,246 vertex comparisons, maximum world error 7.77e-7. Independent Blender-origin witnesses, reversed/repeated sampling and fresh-instance equality also pass.

`browser/` reuses PR60's renderer, lighting, material, camera, controls and exact GLB; all four route variants load the SAME original P2 GLB. The mirrored GLB is an independent test oracle only. Straight/new heading and alternate 60-degree bend are bounded cruise diagnostics; they have not yet received visual acceptance. `hosted/` contains additive preparation, existing-runner Playwright configuration, tests and a branch-only GitHub workflow for the isolated fixture.

Independent expected values are the immutable original/mirrored Python source JSON, not output generated by the port. Evidence logs preserve red-before-green slices: missing adapter; unqualified speeds; invalid calibration, excessive yaw and callback mutation; interpolated yaw overshoot. The first attempted sideways unreachable test was discovered to be physically reachable and corrected to an explicitly impossible shortened limb. All 194 sampled original/mirrored poses check every component of all 22 bone matrices, phase, paw/hip/knee/ankle positions and contact event metadata. Non-monotone repeated queries are deterministic. `node scripts/source-parity.mjs` records the all-matrix maximum error separately. Generic fixed-route acceptance does not certify obstacles or mesh contact.

## Explicit limits

No arbitrary navigation, runtime replan/contact carry-over, acceleration, arrival, action transition, browser/phone performance, or artistic acceptance is established. Native skin parity covers immutable source poses, not collision safety or all subframe deformations. The reference root is a finite authored 90-degree path. Reusing its samples as a looping clip is unsupported. Reach admission is not collision certification. Navigation must later provide a safe swept envelope and retain contacts/phase across route replacement. P2's tiny original sole-plane offsets are not repaired here.

The exact baseline Pip pose driver is retained under `reference/` for read-only architectural comparison; it is not imported. Its eleven-bone calibration, two feet and authored mixer cannot be substituted for Mika.
