# Trusted mixed-source Yard obstacles, closed-gate overlay

Apply after the explicit canonical r5 → Pebble → Pip integration sequence. This archive contains only additive source/test changes; it contains no pixels, no catalog edits, no release-gate changes and no automatic publication.

## Contract

`prop-obstacles.mjs` derives the exact Snack Table and Leaf Pot exclusion rectangles from their frozen combined-source bounds, root origins and 8 logical units/world scale. Leaf Pot keeps its own measured .025-world padding. Registry or player fields cannot supply dimensions.

A context is minted only inside the server dispatcher from exact code-owned, ready binding ID/visitor/prop/revision/phase records. It is branded with a private WeakSet and deeply frozen. Copying or serializing its public shape does not mint another context. Candidate fields, save metadata and action payloads never supply the context argument.

Each actor keeps its original calibrated scene, source clocks, interaction and binding identity. Preflight creates an additional planning scene only when a trusted foreign prop is actually present. All interaction envelopes, prop sweeps, navigation, body-turn and sole-ground checks use it. Unknown props, unaccepted sources, unsupported foreign states and nonzero rotation still reject admission. No obstacle is silently omitted.

Readiness caches include the trusted context revision and distinguish untrusted copies. They do not retain account slot IDs or opaque saved metadata. A foreign-state problem is reported as unavailable source coverage rather than suggesting repair of the wrong target.

New mixed plans record a source/footprint receipt plus a semantic placement hash. Old calibrated media registry bytes and legacy plans remain unchanged. A change to a specifically used foreign source hides that mixed plan's presentation while preserving its original stored visits, routes, gifts and economics. Adding unrelated registry metadata does not invalidate it. Explicitly malformed receipts cannot fall back to legacy compatibility.

## Tests

Run the new focused suite:

    node --test tests/yard-mixed-obstacles.test.mjs

Thirteen focused tests cover:

- Full byte equality of Mika, Mochi, Pip and Pebble media registries against the pre-obstacle checkpoint
- Safe Mika/Mochi visits in one yard with mouse (50,45), Snack Table (50,30), Leaf Pot (30,70), with preserved placement hashes
- Negative full-body interaction collision and entrance blockage
- Independent revalidation of every admitted route's exact sole/turn coverage, using Mika's final pushed mouse for its departure/rest route
- Safe Pip/Leaf Pot and Pebble/Snack Table interactions at each actor's own source timing
- Forged/copied contexts, wrong visitor or revision, inactive binding, missing phases, unknown/prototype-named IDs, worn/broken state and rotated props
- Unchanged old serialized presentation identities and strict legacy registry fallback
- Actual native mixed-yard probabilistic admission, one serving/use, reload compatibility and no spend when a foreign prop becomes unsupported
- Foreign source change invalidates only dependent mixed presentation; unrelated registry additions remain compatible

Source media/atlas bytes and all gate values remain unchanged. The full actor/cache/food/ground/persistence regression suite is recorded in the adjacent stage evidence. No browser, socket, install, Work task or provider generation was run for this patch.

## Acceptance boundary

This closes the trusted mixed-prop planning gap for the four current independently authored sources. It does not establish simultaneous multi-actor choreography or browser acceptance. The existing conservative route reservation policy remains unchanged. All candidate release gates stay closed until the full original Yard scope and browser/visual checks are accepted.
