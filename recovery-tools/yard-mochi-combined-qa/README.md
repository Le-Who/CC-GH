Inactive Mochi media browser harness for the existing authorized GitHub Actions workflow. Run with playwright.mochi.config.js. The local command environment and cloud local URL route are blocked; do not use this harness to bypass those restrictions. This harness is not imported by the production app and creates no live visits or saves. It exercises actual actor/target-prop frame ownership using the packed source and AtlasCache. CI screenshots must be visually reviewed before declaring the browser gate passed. It does not establish full-game food, HUD, network, or release integration QA.

The browser cases live only in tests/yard-mochi-e2e and are selected by playwright.mochi.config.js. The main Playwright config is unchanged. Dedicated artifacts are test-results-mochi/artifacts, test-results-mochi/results.json, and playwright-report-mochi/.
