## CI

Run:

    node --test tests/yard-pip-canonical.test.mjs tests/yard-pip-scene-lifecycle.test.mjs
    npx playwright test --config=playwright.pip-canonical.config.js

The Playwright web server command first regenerates a deterministic fixture and hash whitelist from the final merged canonical source. It then runs the dedicated CI-only server on port 3201. The server requires CI=true and GITHUB_ACTIONS=true, serves only its fixture, the whitelisted canonical modules, and Mika/Pip assets. This uses real root canonical modules, not a stale second source copy.

Upload separately, even on failure:

- test-results-pip-canonical/compact: small phone PNGs, per-viewport JSON and 1x shared-courtyard WebM, suitable for review/download
- test-results-pip-canonical and playwright-report-pip-canonical: full traces/report

The browser matrix covers ten viewport/DPR combinations, exact 40 ms entry/exit/rest seams, completed 52-minute persisted outcome, repeated navigation/reload/rotation, closed-gate zero Pip pixel requests and a delayed-page resize hold. A separate real-time 1x 19.24-second interaction video exposes nibble/back-away/turn/rest continuity and visible ground contact shadows. It does not claim 52 minutes of uninterrupted real-time browser playback.
