# One coherent Yard source frame

This isolated, static Canvas composition draws the saved Basil + Fountain pose at4000ms/frame101 with the45° source camera. It is a single-frame visual diagnostic. It does not run gameplay, APIs, persistence, an animation clock, or an eight-actor acceptance suite.

The entire conservative source mask, original entry90,68 and bowl25,83 remain unchanged. One uniform camera transform scales the source subject and architecture together. The390,320 and landscape scene sizes are390×648,320×372 and754×302. The320 preset uniformly reduces the original width fit by4% to keep the physical porch outside the ground mask. The facade is translated left by10px at390 and the same physical ratio at320; ornamental porch/fence overlap is allowed, while the entire door opening and passage remain clear. Landscape composes the house to the left of the field.

The lawn is one opaque house-free plate with uniform cover/crop. Source-derived exterior edges place foliage, clipped outside both the exact mask and a separate presentation passage. No opaque grass patch paints or blurs the mask. The gate consists of two actual alpha crops at identical scale with a100px opening at390, scaled coherently in other viewports.

`frame.json` pins the untouched source rig, evaluated world geometry, frame, camera, ppu and pivot. `combined45.webp` includes the rendered subject and actual Cycles contact-shadow attenuation. It is640×384,96ppu, pivot449.2013931274414,254.3324432373047. It uses0.9375MiB decoded. Material base colors and all evaluated mesh/bone geometry remain unchanged; lighting, roughness/specularity and a temporary shadow receiver are render-only state. The original.blend was not saved. Shadow max alpha is46/255; the4.04CSSpx softness figure is a geometric light-size bound, not a perceptual edge measurement.

Browser tests capture actual full-canvas, viewport and guide screenshots for all three presets; standalone JSON evidence is written into the test-results directory, alongside the PNGs. It records HTTP body hashes, projection, source pose, memory ledger, draw errors and scope. The ledger includes all six decoded media surfaces, the DPR-capped Canvas and conservative resize reservations. It is not browser RSS or GPU telemetry. A resize case and late-real-bitmap disposal case test lifecycle behavior. No local browser result is claimed; this environment's blocked browser route was not retried.
